"We", "us", "our", "ours" and "ourselves" mean the writer's own organization, while "I", "me" and "my" mean the writer, [[WRITER_NAME]]. Create one entity for that organization, with type organization and the name exactly [[CUSTOMER_NAME]], and use that exact string as source_entity or target_entity in every relationship that is about "we". Never spell it another way or create a second entity for it. If the note also gives the organization's real name, put it in the JSON key "writer_organization" (a string, otherwise null) instead of making a new entity. If the note has no "we", "us" or "our" meaning the writer's organization, create no entity for it.
